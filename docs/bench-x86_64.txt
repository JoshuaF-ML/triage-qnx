Read the rate column. Absolute latencies on QEMU include CPU the
host stole from the guest, which is why this is run as a
differential on one boot rather than quoted as a measurement.

'fcfs queue medium' is what people actually deploy.
'fcfs queue matched' runs the same tiers Triage chose, so it
  isolates scheduling from tier selection -- the honest control.
'fcfs queue all-small' is confounded: it cheapens the flood too.
